# ミリしらソード

PC・スマートフォン対応の、ターン制・見下ろし型文字ブロックパズルです。

通常起動では、日本語斬り／英語斬りで名前付きオブジェクトを文字へ変え、
文字の長さや物理的な配置を利用する14部屋を、一本の道でつながった
ワールドとしてプレイできます。部屋の出口から次の部屋へ歩いて進み、
開通済みの道は後戻りできます。画面上部の部屋選択は会議・確認用の
ファストトラベルとして残しています。

名前付きオブジェクトは文字ラベルではなく簡潔なイラストで表示します。
日本語斬りの名前はすべてひらがなです。

4部屋目ではスライムを斬ると `す・ら・い・む` がすべて出現し、
`い` と `む` を合成壁へ押し込むと、1個の可動文字ブロック `仏` になります。
最後は `KNIGHT` の6文字で三本の視線を遮る15×15の会議用部屋です。

## 操作

- PC: WASD／矢印キーで移動、Jで日本語斬り、Kで英語斬り、Rでリセット
- スマートフォン: 画面下の十字キー、「あ」「A」の斬撃ボタン、画面上部のリセット

## 起動

```powershell
npm.cmd install
npm.cmd run dev
```

表示されたURL（通常は `http://localhost:5173/`）をブラウザで開きます。

## ステージエディター

ゲーム画面右上の `EDITOR`、または次のURLから開きます。

```text
http://localhost:5173/?editor=1
```

壁・床・草地、勇者の開始位置、部屋ごとのパズル基準位置を配置できます。
また、勇者の位置によるカメラ切替範囲と、ゲーム画面へ映す範囲を編集できます。

変更はブラウザ内へ下書き保存されます。`プレイテスト` を押すと、その下書きを
ゲームへ反映して確認できます。バックアップや受け渡しには
`JSON書き出し`／`JSON読み込み`を使用します。

## ビルド

```powershell
npm.cmd test
npm.cmd run test:browser
npm.cmd run build
```

[`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md) に記録します。
