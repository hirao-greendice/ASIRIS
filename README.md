# 知識アンロック — 盤面プロトタイプ

ビルドなしで動く、HTML・CSS・JavaScriptだけのプロトタイプです。`index.html` をブラウザで開いてください。

## 今回実装した範囲

- 画面全体を12列×21行の盤面として表示
- 設定・ステージ番号・ヒント・方向キー・A/Uボタンも盤面座標で配置
- 中央の見かけ上のプレイエリアは10×10、画面全体の論理ステージは12×21
- 中央のSeaは通行不可。Sea上ではLandが置かれたセルだけ移動可能
- Seaの外側は1マス単位のPurple Panelで構成し、UIの裏側も歩行可能
- Purple PanelとLandはセル上辺に揃え、下への出っ張りを立体表現として描画
- Purple PanelとLandは下の行ほど前面に重なる奥行き順
- 設定・ヒント・方向・A・Uは2×2、ステージ番号は4×2
- グリッドの補助線は非表示
- 矢印キーまたは画面ボタンによるトップダウン移動
- 矢印ボタンへ乗ると、その矢印の方向へ自動で移動
- 勇者がボタン上にいる間はボタンが暗くなり、矢印以外のボタンも踏んだ時に作動
- 矢印上で異なる方向を押している間は停止し、離すと自動移動を再開
- Aで向いている方向へ剣を振り、現在地または前方の知識・出口へ作用
- 勇者は上下左右それぞれの通常画像と攻撃画像を使用
- U（またはZ）で一手戻す
- 12×21ステージをワールド座標上に複数追加できるデータ構造
- 画面サイズを変えても12:21を保つレスポンシブ表示

## ステージを増やす場所

`game.js` の `STAGES` に同じ形式のオブジェクトを追加します。

- `position`: 大きなワールド内でのステージ位置
- `start`: プレイヤーの開始セル
- `floor`: 中央に表示する床・足場の見た目
- `holes`: Land上にも追加できる、移動できない穴のセル
- `objects`: 知識や出口などの盤面オブジェクト
- `hint`: ヒントボタンで表示する文

座標はすべて左上を `(0, 0)` とした0始まりです。データが12×21の外に出た場合は、起動時にエラーになる検証を入れています。

UIには `asset` フォルダー内の `*-button.webp` と `stage-display.webp` を使用しています。地形は、素材端の明るい1pxを繰り返してグリッド線にしないため、Sea／Panel／Land素材から取得した面色・側面色と36×44の比率をCSSでそのまま再現しています。
