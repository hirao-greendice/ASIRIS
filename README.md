# スライム・ワープ — 盤面プロトタイプ

ビルドなしで動く、HTML・CSS・JavaScriptだけのプロトタイプです。`index.html` をブラウザで開いてください。

## 今回実装した範囲

- 画面全体を11列×19行の盤面として表示
- 設定・ステージ番号・ヒント・方向キー・A/Uボタンも盤面座標で配置
- 中央の見かけ上のプレイエリアは9×9で、上から3行目・左から2列目に配置
- 中央のSeaは通行不可。Sea上ではLandが置かれたセルだけ移動可能
- Seaの外側は1マス単位のPurple Panelで構成し、UIの裏側も歩行可能
- Purple PanelとLandはセル上辺に揃え、下への出っ張りを立体表現として描画
- Purple PanelとLandは下の行ほど前面に重なる奥行き順
- 設定・ヒントは2×2、ステージ番号は7×2、方向・A・Uは2×2
- 上部UIは上端から設定2列・ステージ7列・ヒント2列の順に、重ならない論理判定として配置
- 上部UIはグリッドの論理判定を維持し、画像を判定範囲より小さくしてPanelが見える余白を確保
- ステージ番号は「Stage 1-1」を横並びで表示
- グリッドの補助線は非表示
- 矢印キーまたは画面ボタンによるトップダウン移動
- 1マス移動は当たり判定を即時更新しつつ、表示を前のマスから滑らかに補間
- 方向入力は押した瞬間に1マス移動し、320ms以上の長押しだけ150ms間隔の連続移動へ移行
- 中央のSeaは9×9へ引き伸ばさず、1マスにつき1枚のSea素材を81枚配置
- 各画面を大きな1つのワールド上へ配置し、隣接画面の端同士を同じ座標で接続
- ワープへ入った進行方向と同じ行・列にある、最も近いワープポイントへ移動
- ワープ到着直後は再発動せず、一度ワープから離れて再進入すると発動
- 矢印ボタンへ乗ると、その矢印の方向へ自動で移動
- 勇者がボタン上にいる間と、プレイヤーが画面・キーボードからボタンを押している間はボタンが暗くなり、矢印以外のボタンも踏んだ時に作動
- 矢印上で異なる方向を押している間は停止し、離すと自動移動を再開
- 追加されたスライム画像を敵として表示し、進路をふさぐ敵をAの剣で倒す
- デザイン案に合わせたStage 1-1〜Stage 7-1と、Stage 4-2／4-3の9画面を収録
- Stage 3-1／4系統の分岐ワープ、Stage 5-1の魔王、Stage 6-1の盤面内矢印、Stage 7-1の盤面外の魔王を配置
- Stage 4-1の上に4-2、その上に4-3を配置し、4-3だけA/Uボタンを右端へ変更
- Stage 5-1から上方向へStage 6-1、そこから右方向へStage 7-1へつながるワープ経路を実装
- デバッグ操作として、`Shift + 矢印キー`でワールド上の隣接ステージへ即時移動
- 両ステージのLandはPanelへ接しない範囲に配置
- 勇者は上下左右それぞれの通常画像と攻撃画像を使用
- U（またはZ）で一手戻す
- 11×19画面をワールド座標上に複数追加できるデータ構造
- 画面サイズを変えても11:19を保つレスポンシブ表示

## ステージを増やす場所

`game.js` の `STAGES` に同じ形式のオブジェクトを追加します。

- `position`: 大きなワールド内でのステージ位置
- `start`: プレイヤーの開始セル
- `floor`: 中央に表示する床・足場の見た目
- `holes`: Land上にも追加できる、移動できない穴のセル
- `objects`: スライムやワープポイントなどの盤面オブジェクト
- `objects` の `kind: "warp"`: 進入方向の直線上にある最寄りワープへ接続
- `hint`: ヒントボタンで表示する文

座標はすべて左上を `(0, 0)` とした0始まりです。データが11×19の外に出た場合は、起動時にエラーになる検証を入れています。

UIには `asset` フォルダー内の `*-button.webp` と `stage-display.webp`、ワープには `warp-point.png` を使用しています。Seaは1マスごとに素材全体を配置し、Panel／Landは素材の面色・側面色と36×44の比率をCSSで再現しています。
