# 知識アンロック — 盤面プロトタイプ

ビルドなしで動く、HTML・CSS・JavaScriptだけのプロトタイプです。`index.html` をブラウザで開いてください。

## 今回実装した範囲

- 画面全体を12列×21行の盤面として表示
- 設定・ステージ番号・ヒント・方向キー・A/Uボタンも盤面座標で配置
- 矢印キーまたは画面ボタンによるトップダウン移動
- Aで知識を取得し、次のステージを解放
- U（またはZ）で一手戻す
- 12×21ステージをワールド座標上に複数追加できるデータ構造
- 画面サイズを変えても12:21を保つレスポンシブ表示

## ステージを増やす場所

`game.js` の `STAGES` に同じ形式のオブジェクトを追加します。

- `position`: 大きなワールド内でのステージ位置
- `start`: プレイヤーの開始セル
- `floor`: 歩けるセル
- `objects`: 知識や出口などの盤面オブジェクト
- `hint`: ヒントボタンで表示する文

座標はすべて左上を `(0, 0)` とした0始まりです。データが12×21の外に出た場合は、起動時にエラーになる検証を入れています。

現段階では色と画像素材を指定していません。仮表示は文字と線だけです。
