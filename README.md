# きりもじ — 最小プロトタイプ

縦固定画面の1ステージ制パズルゲームです。ビルドやインストールは不要です。

## 起動

`index.html` をブラウザで開いてください。ローカルサーバーを使う場合は、たとえば次のコマンドで起動できます。

```powershell
python -m http.server 8000
```

その後、`http://localhost:8000` を開きます。

## 操作

- 画面の十字キー、またはキーボードの矢印キー: 移動
- Bボタン、キーボードの `B` / `Enter`: 調べる・切る・回答する
- Aボタン: 未使用
- ナゾ画面の文字: 回答欄へ何度でも追加

ステージの依存関係は `木 → 石 → 鍵 → 扉` です。
